# 3.1.0 公开预览版检查

检查日期：2026-11-01。维持 **Pre-release**：公开身份的首次安装、授权和 Manico 配置仍需独立 Mac 验收。

| 检查面 | 结果与边界 |
|---|---|
| 配置 | 新格式校验/JSON 往返、旧 windowTag 明确要求重设、混合格式拒绝、保留合法旧目录、转义测试 |
| 路由核心 | 原生资料菜单匹配、隐藏前复查、共享锁、冷启动等待、焦点确认；不依赖窗口名 |
| 自动验证 | Swift 构建、AppleScript 编译、路由保护、14 项 Safari 状态测试、签名和版本检查 |
| 现场证据 | 同源路由核心已完成受控资料切换、改名/空名、单窗口隐藏恢复、Manico 输入链路及全屏跨桌面测试；不等同于公开版在另一台 Mac 首次授权成功 |
| 隐私 | 新的公开提交；无私有提交历史、个人配置/路径/日志、数据库、备份、截图或第三方图标；审核源码、Git 身份及最终 ZIP |
| 升级 | 必须重新确认个人资料菜单名称，旧窗口名不自动映射；取消不覆盖旧配置 |
| 未验 | 公开身份在独立 Mac 首次设置/授权、真实热键；冷启动和系统重启端到端；其他硬件和菜单语言 |
| 公证 | 仅 ad-hoc 签名，没有 Apple Developer ID / notarization |

本版本移植既有本地路由核心，并保留通用配置和公开应用身份。同源核心的现场测试不能替代公开版首次安装验收；受控测试未复现历史焦点超时，不据此声称已查明全部原因。

## 发行物

下载包仅包含两个 Chrome App、可选 Safari App、README、docs、MIT LICENSE 和重新设置脚本。源码 ZIP 由公开 Git HEAD 导出。SHA-256 用于校验完整性，不代表 Apple 公证。

反馈问题请提供 macOS/Chrome/工具版本、操作步骤及脱敏后的状态码，不上传个人配置、全量系统日志或页面截图。
